# Retro_Space_Shooter

A 2D game of a spaceship moving through asteroids and alien enemies.

## 🎮 How to Play
- **Move the spaceship** → Move your wrist left or right to steer.
- **Shoot** → Pinch your thumb and index finger together.
- **Objective** → 
  - Dodge asteroids  
  - Shoot down aliens  
  - Increase your score  
- You start with **3 lives**.

## 🛠️ Tech Stack
- [Pygame](https://www.pygame.org/) — game engine  
- [OpenCV](https://opencv.org/) — computer vision processing  
- [MediaPipe](https://mediapipe.dev/) — hand gesture detection
